## Full datasets (to reproduce manuscript results)

We have submitted our training datasets to [zenodo.org/records/15802811](https://zenodo.org/records/15802811). The datasets are divided into three parts:

### Data folder
The sequence memory map, along with RNA-seq data corresponding to the heart left ventricle, can be downloaded using:

```
cd twinc-paper/
wget https://zenodo.org/records/15802811/files/TwinC_data_resources_V1.tar.gz?download=1
```

After downloading, you can uncompress the file, and it will populate the data folder. 

```
tar -xvzf TwinC_data_resources_V1.tar.gz 
```

### Results folder
Labels for training, as well as intermediate results for reproducing the figures, can be downloaded using:
```
cd twinc-paper/
https://zenodo.org/records/15802811/files/TwinC_label_resources_V1.tar.gz?download=1
```
After downloading, you can uncompress the file, and it will populate the results folder. 

```
tar -xvzf TwinC_label_resources_V1.tar.gz 
```

### Models folder
You can download the pretrained models using:
```
cd twinc-paper/
https://zenodo.org/records/15802811/files/TwinC_models_V1.tar.gz?download=1
```
After downloading, you can uncompress the file, and it will populate the models folder. 

```
tar -xvzf TwinC_models_V1.tar.gz 
```
