# What is TwinC?

TwinC is a Python package for training, inference, and interpretation of trans-3D genome folding in humans. TwinC uses a Convolutional Neural Network model that predicts contact between two _trans_ genomic loci from nucleotide sequences. The model takes two 100 kbp nucleotide sequences as input and treats the task of predicting _trans_ contacts as a classification task. To reproduce analyses performed in [Jha et al. (2024)](https://pmc.ncbi.nlm.nih.gov/articles/PMC11429679/), please check out [TwinC 2024 manuscript repository](https://github.com/Noble-Lab/twinc_paper).
